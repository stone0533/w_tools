# ui 13.0 迁移

> 基线：`w_tools_ui` 12.0.1 → 13.0.0。两个 breaking 一起发布；都属于“删掉多余入口”。

## 1. `WButton` 改用 named constructors

构造器只表达按钮类型；`style` 只覆盖属性，不再能选择按钮类型。

```dart
// before
WButton(label: '保存', onTap: save);
WButton(variant: WButtonVariant.outlined, label: '取消', onTap: cancel);
WButton(variant: WButtonVariant.danger, label: '删除', onTap: remove);

// after
WButton.filled(label: '保存', onTap: save);
WButton.outlined(label: '取消', onTap: cancel);
WButton.filled(style: AppButtons.danger(context), label: '删除', onTap: remove);
```

删除的公开名：

- `WButton(...)` 无名构造器；
- `WButton.variant` / `WButtonVariant`；
- `WButtonTheme.styleFor(...)`；
- `WButtonTheme.danger`（含 `copyWith` / `lerp` 的 `danger` 参数）。

危险色不再是类型：用项目 `AppButtons.danger(context)` 或

```dart
WButton.filled(
  style: FilledButton.styleFrom(
    backgroundColor: Theme.of(context).colorScheme.error,
    foregroundColor: Theme.of(context).colorScheme.onError,
  ),
  label: '删除',
  onTap: remove,
);
```

`WButtonTheme` 只剩 `filled` / `outlined` / `text` 三个类型槽。

## 2. `WScaffold.basic` 删除

```dart
// before
WScaffold.basic(
  title: '订单详情',
  actions: [IconButton(...)],
  body: ...,
);

// after
WScaffold(
  appBar: WAppBar(
    title: '订单详情',
    actions: [IconButton(...)],
  ),
  body: ...,
);
```

删除的公开成员：

- `WScaffold.basic`；
- 只服务 `.basic` 的 `title` / `titleWidget` / `leading` / `actions` / `onBack` /
  `automaticallyImplyLeading` / `centerTitle` / `appBarStyle` / `appBarBottom`。

`WScaffold(appBar: ...)` 的 body / drawer / bottomSheet / bottomNavigationBar / FAB /
安全区参数不变；`appBar` 仍可传任意 `PreferredSizeWidget`。

## 3. 自检

```bash
grep -rn "WButtonVariant\|WScaffold.basic" lib
grep -rn "WButton(" lib   # 确认没有无意保留的无名构造器
```

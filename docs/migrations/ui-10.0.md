# ui 10.0 迁移

10.0 删除 9.0 弃用的全局 `WScreen` 入口，并删除 `WNumExtension.borderSide`。
其余 API 与 9.0 一致。

## 1. WScreen：只保留 scope

9.0 已推荐 `WScreenScope`；10.0 删除静态入口，`WScreen.of` 不再回退全局 delegate。

```dart
// 9.x（已弃用，10.0 删除）
WScreen.w(16);
WScreen.h(24);
WScreen.sp(14);
WScreen.delegateWidth = (v) => ScreenUtil().setWidth(v);

// 10.0
WScreenScope(
  widthScaler: (v) => ScreenUtil().setWidth(v),
  heightScaler: (v) => ScreenUtil().setHeight(v),
  fontScaler: (v) => ScreenUtil().setSp(v),
  child: app,
);

final screen = WScreen.of(context);
screen.w(16); screen.h(24); screen.sp(14);
```

删除的成员：`WScreen.w` / `h` / `sp` / `delegateWidth` / `delegateHeight` /
`delegateFont` / `reset`。没有 scope 时 `WScreen.of(context)` 的 `w/h/sp` 是恒等函数。

## 2. borderSide

`WNumExtension.borderSide` 已删除；边框统一用主题描边色：

```dart
// 9.x（已弃用，10.0 删除）
2.borderSide(color: Colors.grey);

// 10.0
2.borderSideOf(context);
```

## 3. 从 9.0 继承的未发布变更

10.0 同时包含 9.0 的未发布改动；细节见 [ui-9.0](ui-9.0.md)。涉及的公开成员：
`WImageStyle.copyWith`、`WImageLoadOptions.copyWith`、`WImageErrorKind.empty`（删除）、
`WBadge.new`、`WButtonSemantics.new`、`WImageErrorView.new`、`WScreenData.new`。

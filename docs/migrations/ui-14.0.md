# ui 14.0 迁移

> 基线：`w_tools_ui` 13.0.0 → 14.0.0。只改名，行为不变。

## `WImage.source` → `WImage`

`WImage.source` 是 6.0 图片入口收敛时留下的命名；现在它是唯一入口，改为无名构造器：

```dart
// before
WImage.source(
  source: WImageSource.network(url),
  style: const WImageStyle(width: 120, height: 120),
)

// after
WImage(
  source: WImageSource.network(url),
  style: const WImageStyle(width: 120, height: 120),
)
```

- 只删除构造器名 `WImage.source`；
- `source:` / `style:` / `options:` / `slots:` / 回调参数与默认值不变；
- 迁移是机械替换 `WImage.source(` → `WImage(`；
- `WImageSource`、`WImageStyle`、`WImageLoadOptions`、`WImageSlots`、`WImageTheme`
  均不变。

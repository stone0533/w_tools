# ui 12.0 迁移

12.0 是**纯减法**：删除一批镜像式 / 从未被消费的公开入口，不新增能力。
组件行为、默认样式与 11.0 一致（除下文标注的 4 个修复）。

## 快速替换表

| 11.0 旧入口 | 12.0 替代 | 说明 |
|---|---|---|
| `WStepFlow(labels: ...).build(current: n)` | `WStep(labels: ..., current: n)` | `WStepFlow` 只是 `WStep` 的参数镜像；复用直接复用参数 |
| `WNavBar(style: WNavBarStyle(...))` | `WNavBar(decoration: ..., padding: ...)` | `WNavBarStyle` 只有这两个字段 |
| `WNavController(length: 3, vsync: this)` | `WNavController(length: 3)` | controller 不再持有动画，不需要 `TickerProviderStateMixin` |
| `controller.animateTo(2)` | `controller.currentIndex = 2` | 选中态直接切换；过渡动画由页面自己画 |
| `controller.previousIndex` / `indexIsChanging` / `offset` / `animation` | 无替代 | 这些成员从未被 `WNavBar` 消费 |
| `key.offset()` / `key.rect()` | `key.currentContext?.findRenderObject()` + `localToGlobal` / `paintBounds` | 仅两行代码，不再单独提供扩展 |
| `16.heightBox` / `16.widthBox` / `16.squareBox` | `SizedBox(height: 16)` / `SizedBox(width: 16)` / `SizedBox.square(dimension: 16)` | 原生构造 |
| `16.horizontalPadding` / `16.verticalPadding` | `EdgeInsets.symmetric(horizontal: 16)` / `vertical: 16` | 原生构造 |
| `16.borderRadius` | `BorderRadius.circular(16)` | 原生构造 |
| `'42'.toInt()` / `'3.14'.toDouble()` / `'1e3'.toNum()` | `int.tryParse` / `double.tryParse` / `num.tryParse` | Dart 原生 |
| `' a b '.trimAll()` | `replaceAll(RegExp(r'\s+'), '')` | Dart 原生 |
| `decoration.withColor(c)` / `withBorder(...)` / `withBorderRadius(...)` / `withShadow(...)` / `withShape(...)` | 直接传 `BoxDecoration(...)`；唯一背景用 `withBackground`，圆形用 `circle` | 扩展只保留有跨字段约束的两处组合 |
| `WNotificationListener(preventNotificationPropagation: true)` | `onNotification: (_) => true` | 返回值本身就是阻止冒泡 |
| `WPressable(hasChildSemanticsWhenDisabled: false)` | 外层包 `ExcludeSemantics` | 默认行为（保留语义）不变 |
| `WImageErrorView(compact: true)` | 不传 `compact`；小尺寸会按可用高度自动只显示图标 | 少一套开关 |
| `WScaffold(underlayWidget: ...)` | 页面层 `Stack`（背景放底层） | scaffold 不再承担叠层 |
| `WImageStyle.avatar(40)` | `WImageStyle(width: 40, height: 40, borderRadius: BorderRadius.circular(20))` | 预设只是这两行 |
| `WImageStyle.thumbnail(80)` | `WImageStyle(width: 80, height: 80)` | 预设只是这两行 |
| `WTabBar(tabs: ..., style: WTabBarStyle(...))` | `TabBar(tabs: ..., ...)` + `TabBarTheme` | 22 个字段一键换名，`WTabBar` 没有额外默认值 |
| `WTabBarStyle.noSplash` | `overlayColor: WidgetStatePropertyAll(Colors.transparent)` + `splashFactory: NoSplash.splashFactory` | 直接传 `TabBar` |
| `WImage.source(controller: c)` + `c.retry()` | `slots: WImageSlots(errorWidgetBuilder: (c, d, e, retry) => WImageErrorView(error: e, onRetry: retry))` | 手动重试从 controller 移到 error slot |
| `WImageController.state` / `WImageLoadSnapshot` | `onLoadStatusChanged` / `onProgress` | 状态与进度都是回调 |
| `WImageSlots(emptyBuilder: ...)` / `progressBuilder: ...` | `placeholderBuilder` | 空 / 加载中 / 等待重试共用一个占位 |
| `WImageSlots(showRetryButton: true)` | `errorWidgetBuilder` 返回 `WImageErrorView` | 重试按钮回到错误 UI 自己决定 |
| `WImageStyle(padding: ...)` / `margin: ...` | 外层 `Padding` / `Container` | 尺寸语义与 Flutter 一致 |
| `WImageSource.parse(raw)` | `WImageSource.network/asset/file/base64/provider` | 类型显式选择，不再猜 |
| `WImageSource.asset('logo.png', prefix: true)` | `WImageSource.asset('assets/images/logo.png')` | 完整路径 |
| `WAssets.imagePath = 'assets/'` / `'logo.png'.assetImagePath` | `WImageSource.asset('assets/logo.png')` | 全局前缀删除 |
| `1234.toThousandsSeparated` / `toCurrency` / `toPercent` / `toPadLeft` | 换 `package:w_tools_core/w_tools_core.dart` | 数字格式化迁到 core 3.2.0，方法名不变 |
| `WButton(style: WButtonStyle.filled(...))` | `WButton(variant: ..., style: FilledButton.styleFrom(...))` | `style` 现在是 Material `ButtonStyle` |
| `WButtonStyleSet.of(context).primary/secondary/text/danger` | `WButtonVariant.filled/outlined/text/danger` 或 `WButtonTheme` | 四种语义变体 |
| `WButton(motion: WButtonMotion(...))` | 无替代 | 按压反馈交给 Material ink |
| `WButton(semantics: WButtonSemantics(...))` | `semanticLabel` / `semanticHint` / `loadingLabel` | 直接参数 |
| `WButton(contentBuilder: (c, style) => ...)` | `WButton(content: ...)` | content 内的 Text / Icon 自动继承按钮前景色 |
| `'#RRGGBBAA'` 交给 `fromHex` | `WColorExtension.fromCssHex` / `toCssHex` / `'#RRGGBBAA'.toCssColor()` | 字节序显式选择；`fromHex` 仍是 AARRGGBB |

## 4 个修复（不是 API 改名）

- `WScaffold.basic(title: '')`：以前静默**不渲染**顶栏（返回按钮也一起消失），现在一定渲染；
  只有标题文本为空。
- `WScaffold`：删除重复两遍的 `includeStatusBar` 断言与恒真的互斥断言（行为不变）。
- `WButtonStyle`：只有 `borderRadius`、没有任何可绘制装饰时不再多包一层 `DecoratedBox`。
- `WSelectableRow`：删除从未被读取的滚动视图 key（行为不变）。

```bash
grep -rn "WStepFlow\|WNavBarStyle\|WGlobalKeyExtension\|heightBox\|widthBox\|squareBox" lib
grep -rn "WTabBar\|WImageController\|showRetryButton\|emptyBuilder\|progressBuilder" lib
grep -rn "WImageSource.parse\|WAssets\|assetImagePath\|prefix: true" lib
grep -rn "WImageStyle(.*\(margin\|padding\)" lib
grep -rn "WButtonStyle\|WButtonMotion\|WButtonSemantics\|WButtonContentBuilder" lib
grep -rn "toThousandsSeparated\|toCurrency\|toPercent" lib
grep -rn "horizontalPadding\|verticalPadding\|trimAll\|preventNotificationPropagation" lib
grep -rn "hasChildSemanticsWhenDisabled\|underlayWidget\|WImageStyle.avatar\|WImageStyle.thumbnail" lib
grep -rn "animateTo\|previousIndex\|indexIsChanging\|WNavController(" lib
```

然后按替换表改；`analyze` 会兜住剩下的引用。

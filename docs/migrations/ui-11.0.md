# ui 11.0 迁移

## 删除 `WClipRRect`

`WClipRRect` 是 Flutter `ClipRRect` 的纯别名，默认值完全一致
（`borderRadius = BorderRadius.zero`、`clipBehavior = Clip.antiAlias`）。

```dart
// 旧
WClipRRect(borderRadius: BorderRadius.circular(12), child: image)

// 新
ClipRRect(borderRadius: BorderRadius.circular(12), child: image)
```

图片圆角仍然优先用 `WImageStyle.borderRadius`；`ClipRRect` 只用于非图片内容的裁剪。

## 删除 `WNavBar.onItemTap`

改用 `onBeforeTap`；返回 `false` 阻止切换，同步 / 异步都支持。

```dart
// 旧
WNavBar(
  controller: nav,
  onItemTap: (index) async {
    if (!canSwitch(index)) return false;
    return true;
  },
  itemBuilder: ...,
)

// 新
WNavBar(
  controller: nav,
  onBeforeTap: (index) async {
    if (!canSwitch(index)) return false;
    return true;
  },
  itemBuilder: ...,
)
```

## 删除 `notifyScrollPercentage`

它是内部实现细节；需要百分比时直接读 `ScrollNotification.metrics`。

```dart
final fraction = notification.metrics.maxScrollExtent <= 0
    ? 0.0
    : (notification.metrics.pixels / notification.metrics.maxScrollExtent)
          .clamp(0.0, 1.0);
```

## 删除 `WTextStyleExtension`

直接用 Flutter `TextStyle.copyWith`：

```dart
// 旧
style.bold;
style.withColor(Colors.red);
style.withSize(20);

// 新
style.copyWith(fontWeight: FontWeight.bold);
style.copyWith(color: Colors.red);
style.copyWith(fontSize: 20);
```

## 删除 `WUiWidgetExtension`

`WUiWidgetExtension` 合并到 `WWidgetExtension`；`toPressable` 方法本身仍然可用，
调用点不需要改，只有显式引用类型名的代码需要改成 `WWidgetExtension`。

## `WImageError.data` → `WImageError.sourceValue`

字段改名；构造器仍是位置参数，调用点不用改。

```dart
// 旧
error.data;
error.toString(); // WImageError(..., data: ...)

// 新
error.sourceValue;
error.toString(); // WImageError(..., source: ...)
```

## `WListViewSliver.keepAlive` → `addAutomaticKeepAlives`

参数改名，语义与 Flutter 的 `addAutomaticKeepAlives` 对齐：它只启用保活机制，
子项仍需 `WKeepAliveWrapper` / `AutomaticKeepAliveClientMixin` 才会真正保留状态。

```dart
// 旧
WListViewSliver.list(keepAlive: true, ...)

// 新
WListViewSliver.list(addAutomaticKeepAlives: true, ...)
```

## `WButtonStyles` → `WButtonStyleSet.of(context)`

类型合并：`WButtonStyles.of(context)` 改到 `WButtonStyleSet.of(context)`，返回值与字段不变。

```dart
// 旧
WButtonStyles.of(context).primary;

// 新
WButtonStyleSet.of(context).primary;
```

> 迁移记录：只描述从旧版本升级的步骤，不代表当前公开 API。

# ui 11.0 迁移

## 删除 `WClipRRect`

`WClipRRect` 是 Flutter `ClipRRect` 的纯别名，默认值完全一致
（`borderRadius = BorderRadius.zero`、`clipBehavior = Clip.antiAlias`）。

```dart
// 旧
WClipRRect(borderRadius: BorderRadius.circular(12), child: image)

// 新
ClipRRect(borderRadius: BorderRadius.circular(12), child: image)
```

图片圆角仍然优先用 `WImageStyle.borderRadius`；`ClipRRect` 只用于非图片内容的裁剪。

## 删除 `WNavBar.onItemTap`

改用 `onBeforeTap`；返回 `false` 阻止切换，同步 / 异步都支持。

```dart
// 旧
WNavBar(
  controller: nav,
  onItemTap: (index) async {
    if (!canSwitch(index)) return false;
    return true;
  },
  itemBuilder: ...,
)

// 新
WNavBar(
  controller: nav,
  onBeforeTap: (index) async {
    if (!canSwitch(index)) return false;
    return true;
  },
  itemBuilder: ...,
)
```

## 删除 `notifyScrollPercentage`

它是内部实现细节；需要百分比时直接读 `ScrollNotification.metrics`。

```dart
final fraction = notification.metrics.maxScrollExtent <= 0
    ? 0.0
    : (notification.metrics.pixels / notification.metrics.maxScrollExtent)
          .clamp(0.0, 1.0);
```

## 删除 `WTextStyleExtension`

直接用 Flutter `TextStyle.copyWith`：

```dart
// 旧
style.bold;
style.withColor(Colors.red);
style.withSize(20);

// 新
style.copyWith(fontWeight: FontWeight.bold);
style.copyWith(color: Colors.red);
style.copyWith(fontSize: 20);
```

## 删除 `WUiWidgetExtension`

`WUiWidgetExtension` 合并到 `WWidgetExtension`；`toPressable` 方法本身仍然可用，
调用点不需要改，只有显式引用类型名的代码需要改成 `WWidgetExtension`。

## `WImageError.data` → `WImageError.sourceValue`

字段改名；构造器仍是位置参数，调用点不用改。

```dart
// 旧
error.data;
error.toString(); // WImageError(..., data: ...)

// 新
error.sourceValue;
error.toString(); // WImageError(..., source: ...)
```

## `WListViewSliver.keepAlive` → `addAutomaticKeepAlives`

参数改名，语义与 Flutter 的 `addAutomaticKeepAlives` 对齐：它只启用保活机制，
子项仍需 `WKeepAliveWrapper` / `AutomaticKeepAliveClientMixin` 才会真正保留状态。

```dart
// 旧
WListViewSliver.list(keepAlive: true, ...)

// 新
WListViewSliver.list(addAutomaticKeepAlives: true, ...)
```

## `WButtonStyles` → `WButtonStyleSet.of(context)`

类型合并：`WButtonStyles.of(context)` 改到 `WButtonStyleSet.of(context)`，返回值与字段不变。

```dart
// 旧
WButtonStyles.of(context).primary;

// 新
WButtonStyleSet.of(context).primary;
```

## `WImageFrame` 不再从 barrel 导出

`WImageFrame` 是 `WImage` 内部的装饰层；图片圆角 / 边框 / 阴影继续用 `WImageStyle`。
需要单独给任意 child 做装饰时，用 `Container` / `DecoratedBox` / `ClipRRect`。

## `WImageStyle` 几何类型放宽

`borderRadius` 从 `BorderRadius` 改为 `BorderRadiusGeometry`；
`margin` / `padding` 从 `EdgeInsets` 改为 `EdgeInsetsGeometry`。
传 `BorderRadius` / `EdgeInsets` 的旧代码仍然兼容。

## `WWidgetExtension` 精简

删除 6 个物理 padding 方法，直接用 Flutter `Padding`：

```dart
// 旧
widget.withHorizontalPadding(8);
widget.withVerticalPadding(4);
widget.withLeftPadding(4);
widget.withRightPadding(6);
widget.withTopPadding(8);
widget.withBottomPadding(8);

// 新
Padding(padding: const EdgeInsets.symmetric(horizontal: 8), child: widget);
Padding(padding: const EdgeInsets.symmetric(vertical: 4), child: widget);
Padding(padding: const EdgeInsets.only(left: 4), child: widget);
Padding(padding: const EdgeInsets.only(right: 6), child: widget);
Padding(padding: const EdgeInsets.only(top: 8), child: widget);
Padding(padding: const EdgeInsets.only(bottom: 8), child: widget);
```

RTL 场景继续用 `withStartPadding` / `withEndPadding`。

`withBottomBarSpaceOf` 改名 `withBottomSafeSpaceOf`（语义更准确）：

```dart
// 旧
widget.withBottomBarSpaceOf(context);

// 新
widget.withBottomSafeSpaceOf(context);
```

## `WStep` 构造时复制 `labels`

`WStep` 在构造时复制并冻结 `labels`，所以不再是 `const` 构造器：

```dart
// 旧
const WStep(labels: ['下单', '付款'], current: 1);

// 新
WStep(labels: const ['下单', '付款'], current: 1);
```

好处是外部修改原列表不会影响已构建的步骤条；`WStepFlow` 原本就会复制。

## `WImageSlots` 只保留 builder

删除固定 Widget 入口 `placeholder` / `emptyWidget` / `errorWidget`，统一用 builder：

```dart
// 旧
WImageSlots(
  placeholder: const _Placeholder(),
  emptyWidget: const SizedBox.shrink(),
  errorWidget: const _ErrorBox(),
)

// 新
WImageSlots(
  placeholderBuilder: (context, data) => const _Placeholder(),
  emptyBuilder: (context, data) => const SizedBox.shrink(),
  errorWidgetBuilder: (context, data, error) => const _ErrorBox(),
)
```

builder 返回 `null` 时回退到内置兜底；`WImageTheme` 与单图 slots 的合并规则不变。
